# Chrome 网上应用店资料

## 基本信息

- 名称：微小读
- 短描述：让阅读与书籍管理更顺手。
- 类别：生产力工具
- 关系说明：非微信读书或腾讯官方产品。

## 详细描述

微小读让微信读书网页版的找书流程更顺手：在搜索框下方查看最近 5 个搜索词，点击即可重新搜索；搜索结果中的可读书籍若尚未加入书架，会出现“加入书架”按钮。已经加入书架的书不显示按钮。

扩展仅在微信读书网页版运行，不需要单独账号。最近搜索只保存在当前浏览器。书架操作由微信读书处理。

## 隐私字段建议

- 单一用途：改善微信读书网页版的搜索和加入书架流程。
- 权限说明：`storage` 用于在当前浏览器保存最近搜索；站点访问范围仅为 `weread.qq.com`，用于显示按钮与发起用户点击的书架操作。
- 数据披露：按实际版本如实披露搜索词与书籍 ID 的处理；扩展会向微信读书重新请求当前搜索结果，不向开发者服务器发送这些数据。以公开的 `PRIVACY.md` 页面作为隐私政策地址。

## 提交前素材

- 使用 `extension/icons` 中的原创图标。
- 截取至少一张安装扩展后的真实搜索界面，清晰展示最近搜索与“加入书架”按钮，勿包含私人书架或账号信息。
- 在开发者后台填写有效支持邮箱、公开隐私政策 HTTPS 地址，并逐项核对隐私披露。
