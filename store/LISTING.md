# Chrome 网上应用店资料

## 基本信息

- 名称：微小读 · 微信读书网页版助手
- 短描述：微信读书网页版的非官方扩展。选中书名即可右键搜书，还支持最近搜索、封面简介预览和快捷加入书架。
- 类别：生产力工具
- 关系说明：非微信读书或腾讯官方产品。

## 详细描述

微小读是微信读书网页版的非官方 Chrome 扩展。

在文章或书单里看到想读的书？选中书名，比如「局外人」，右键点击「在微信读书里搜索 -> 局外人」，即可在新标签页查看图书搜索结果。

- 直达首页。没选中文字时，在网页空白处右键点击「去微信读书」。
- 最近搜索。点击微信读书的空白搜索框，可查看最近 5 个不同的搜索词，选一条即可重搜。
- 封面简介预览。将鼠标停在首页推荐、榜单或搜索结果的书籍封面上，即可查看简介。
- 快捷加入书架。登录后，可在搜索结果中把尚未收藏的可读书籍直接加入书架。
- 回到刚才。通过目录跳章后，点击「回到刚才」，继续读跳转前的位置。净向前读 3 页或 3 屏且在阅读页前台累计停留 45 秒后，按钮会自动收起。

扩展仅在微信读书网页版注入脚本，不需要单独账号。站内最近搜索只保存在当前浏览器，右键搜索词不计入其中。书架操作由微信读书处理。

## 隐私字段建议

- 单一用途：改善微信读书网页版的找书和阅读流程。
- 权限说明：`storage` 用于在当前浏览器保存最近搜索，`contextMenus` 用于提供「去微信读书」和「在微信读书里搜索」菜单，并在用户点击搜索菜单时获取选中的文字。脚本仅注入 `weread.qq.com`，用于搜索增强、简介预览、书架操作和恢复读到的位置。
- 数据披露：用户点击「在微信读书里搜索」后，所选文字仅用作微信读书图书搜索页的关键词。站内搜索时，扩展会向微信读书重新请求当前搜索结果。首页或搜索结果的书籍缺少简介时，触发预览后按需请求该书的公开阅读页。简介和出版信息仅缓存在当前页面。目录跳章前的书籍、章节标识、章内位置以及判断何时收起按钮所需的阅读距离和前台停留时间暂存在当前阅读页内存中。点击「回到刚才」时，位置交给原生阅读器恢复，必要时用微信读书的阅读链接携带该位置。扩展不向开发者服务器发送这些数据。以公开的 `PRIVACY.md` 页面作为隐私政策地址。

## 提交前素材

- 使用 `extension/icons` 中的原创图标。
- 截取至少一张安装扩展后的真实搜索界面，清晰展示最近搜索与“加入书架”按钮，勿包含私人书架或账号信息。
- 在开发者后台填写有效支持邮箱、公开隐私政策 HTTPS 地址，并逐项核对隐私披露。
